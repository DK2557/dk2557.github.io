## Headings

Use headings to organize notes into sections such as days, topics, or projects.

- Use one level-one heading for the notebook title.
- Use level-two headings for major topics.
- Use level-three headings for Notes, Practice, and Reflections.

## Text Formatting

Use bold for key terms, italic for emphasis, and inline code for keywords, functions, or commands.

Example: Class is a blueprint for objects. Remember to test your code. Use std::cout to print.

## Code Blocks

Use fenced code blocks whenever you write multiple lines of code.

Example C++ block:

    #include <iostream>
    int main() {
        std::cout << "Hello";
        return 0;

## Style Rules

- Consistency matters more than creativity.
- Always use headings to structure notes.
- Use code blocks for multi-line code.
- Clarity first: bold key terms and use lists for outlines.
- Keep a professional tone.
- Track learning with checklists and reflections.

## Bottom Line

Headings provide structure. Bold and italic add emphasis. Code blocks hold code. Lists organize steps. Tables organize comparisons. Checklists track progress.
